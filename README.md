# 👕 Garment Worker Productivity Dashboard

## 📌 Project Overview

The **Garment Worker Productivity Dashboard** is an interactive data visualization project designed to analyze and monitor the productivity of garment workers across different departments, teams, and production periods.

The dashboard provides insights into actual productivity, target achievement, overtime patterns, and departmental performance. It helps identify productivity trends, compare worker performance against targets, and understand differences in performance across teams.

## 🎯 Objectives

- Monitor overall garment worker productivity.
- Compare actual productivity against targeted productivity.
- Analyze productivity across different departments and teams.
- Identify trends in productivity across production periods.
- Examine the relationship between overtime and actual productivity.
- Identify teams and departments that require performance improvement.

## 📊 Dashboard Features

### 1. Productivity Overview (KPIs)

The dashboard displays four key performance indicators:

| KPI | Description |
|---|---|
| Total Records | Total number of records available in the dataset. |
| Target Achievement Rate | Measures the extent to which actual productivity meets the target. |
| Average Actual Productivity | Average productivity achieved by workers. |
| Average Target Productivity | Average expected productivity based on production targets. |

### 2. Distribution of Actual Productivity
- Displays the distribution of actual productivity values.
- Helps understand the frequency of different productivity levels.
- Identifies common productivity ranges and variations.

### 3. Overtime vs Actual Productivity
- Visualizes the relationship between overtime hours and actual productivity.
- Helps examine whether additional working hours are associated with changes in productivity.
- Differentiates between finishing and sewing departments.

### 4. Department Ranking Across Production Periods
- Compares the productivity of finishing and sewing departments.
- Shows departmental performance across different quarters.
- Helps identify productivity variations over time.

### 5. Productivity Difference from Target by Team
- Displays the difference between actual and targeted productivity for individual teams.
- Helps identify teams performing above or below their targets.
- Supports team-level performance evaluation.

### 6. Actual vs Target Productivity by Department
- Compares average actual productivity with average targeted productivity.
- Provides a department-level overview of target achievement.
- Helps identify performance gaps between departments.

## 🎛️ Interactive Filters

The dashboard includes four interactive filters:

- **Department:** Filter data by department.
- **Team:** View productivity information for a specific team.
- **Period:** Analyze productivity across selected production periods.
- **Date:** Filter records based on specific dates.

These filters allow users to explore the data from different perspectives.

## 💡 Key Insights

The dashboard enables users to:

- Evaluate overall productivity and target achievement.
- Compare the performance of sewing and finishing departments.
- Identify teams with productivity gaps.
- Understand productivity distribution across workers.
- Investigate the relationship between overtime and productivity.
- Track changes in departmental performance across production quarters.
